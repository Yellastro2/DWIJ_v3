# Движ

Android-плеер с собственным интерфейсом и кодовой базой. Работает с Яндекс
Музыкой и музыкой, которая уже лежит на устройстве.

## Что уже умеет

- Авторизация в Яндекс Музыке через OAuth Device Flow.
- «Моя волна»: запуск радио, подгрузка треков и корректные feedback-события
  для старта, пропуска и прослушивания.
- Воспроизведение в фоне через Media3 / MediaSession: очередь, переключение
  треков, обложка, экран плеера и системные элементы управления.
- Библиотека Яндекс Музыки: плейлисты, любимые треки, создание плейлистов,
  добавление и удаление треков без ручного обновления экрана.
- Отправка событий прослушивания в Яндекс Музыку.
- Локальная медиатека: чтение аудиофайлов и плейлистов из MediaStore,
  собственный быстрый каталог в Room и фоновая синхронизация изменений.
- Локальные плейлисты Движа с экспортом в M3U, чтобы ими могли пользоваться
  другие плееры на устройстве.
- Переключатель источника на главном экране: Яндекс Музыка или локальная
  библиотека; для каждого доступны свои «Все треки» и плейлисты.
- Единая доменная модель песни поверх источников: одна логическая песня может
  иметь версии из Яндекс Музыки и локального файла. Для похожих, но не
  однозначных совпадений готовится список кандидатов на объединение.

## Устройство проекта

- `:app` — приложение, Compose-интерфейс, локальная база, синхронизация
  MediaStore и сервис воспроизведения.
- `:yaMusicSdk` — отдельная Kotlin/Android-библиотека для API Яндекс
  Музыки: типизированные ответы, авторизация, каталог, плейлисты, радио,
  загрузка медиа и feedback.

Модуль Яндекс Музыки создан на основе контрактов и поведения
[MarshalX/yandex-music-api](https://github.com/MarshalX/yandex-music-api),
не является его построчным переносом на Kotlin.
