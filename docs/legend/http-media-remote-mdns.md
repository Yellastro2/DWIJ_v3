# Объявление HTTP-пульта через mDNS / DNS-SD

## Формат

- Тип сервиса: `_http._tcp.local.` (Android NSD принимает `_http._tcp.`).
- Имя экземпляра: `DWIJ`; TXT `app=dwij` отличает пульт от других HTTP-сервисов.
- Объявляется фактический порт HTTP-пульта, по умолчанию 8765.
- Команды: `POST /previous`, `POST /play-pause`, `POST /next`; ответ 204 означает постановку команды в очередь.
- DNS-SD имя экземпляра сервиса **не равно** DNS-имени хоста. Надпись `Имя сервиса: DWIJ` не означает доступность `http://dwij.local`.

## Реализация и жизненный цикл

- `HttpMediaRemote` запускает объявление после открытия порта; при выключении, смене порта и завершении runtime снимает прежнее объявление.
- Android: `AndroidHttpMediaServiceAdvertiser`, системный `NsdManager`. Фактическое имя берётся из `onServiceRegistered`, включая автоматический суффикс при конфликте.
- Desktop: `DesktopHttpMediaServiceAdvertiser`, JmDNS 3.6.3 на IPv4, отображаемом в настройках. После `registerService` используется `ServiceInfo.name`, которое библиотека может изменить при конфликте.
- Сетевые операции объявления не блокируют UI. Устаревшие результаты регистрации после выключения/смены порта игнорируются и освобождаются.
- Карточка наблюдает имя через `StateFlow`; до успешной регистрации имя не отображается. Ошибки объявления пишутся в журнал, HTTP-пульт продолжает работать.

## Ограничения и проверка

- Успешная регистрация не подтверждает видимость со второго устройства и не определяет блокировку multicast роутером.
- Проверять обнаружение со второго устройства в той же сети, затем отправить HTTP-команду на разрешённый адрес и объявленный порт.
- Проверить два экземпляра DWIJ: сервисы должны получить разные имена. Проверить смену порта и выключение: прежнее объявление должно исчезнуть после обновления клиентского кеша.
- Desktop привязан к выбранному IPv4. После смены сетевого интерфейса необходимо выключить и включить пульт; при нескольких сетях выбранный адрес может оказаться не адресом Wi-Fi.
- HTTP-пульт не требует авторизации; mDNS добавляет обнаружение, не меняя этот контракт.
