# Похожие музыкальные приложения

## BitChord

[Репозиторий BitChord](https://github.com/kushagrasinghx/BitChord) — полезный
референс для DWIJ: музыкальный клиент с Android-приложением и desktop-версией,
общим Kotlin Multiplatform-модулем и Compose Multiplatform. Интерфейс вдохновлён
Apple Music.

Локальная копия исходников на компьютере разработчика: `D:\ExternalRepos\BitChord`
(путь проверен 2026-10-08). Использовать её для чтения и сверки реализации
интеграций, авторизации и плеера; для сборки DWIJ эта папка не требуется.

Проверено по документации проекта 2026-10-07. Приложение не запускалось,
реализация интеграций в исходниках в рамках этой заметки не исследовалась.
Ниже перечислены заявленные возможности, а не результаты проверки работы.

### YouTube Music и Spotify

- **YouTube Music:** поиск, просмотр каталога и воспроизведение; вход через
  Google для персонального контента.
- **Spotify:** подключение аккаунта для воспроизведения плейлистов и Liked Songs.
  README не объясняет, откуда берётся аудио для этих треков. Нельзя на основании
  этого описания считать подтверждённым прямой стриминг из Spotify: источник
  звука и механизм сопоставления нужно отдельно проверить в коде.
- **Другие источники:** настраиваемые модули источников, lossless FLAC/ALAC
  из подключённого модуля с резервным воспроизведением через YouTube Music.
- **Локальная музыка и офлайн:** интеграция локальной медиатеки и скачивание
  треков с метаданными.

### Что полезно изучить для DWIJ

- Организацию общей логики и UI между Android и desktop: каталоги `shared/`,
  `sharedUi/`, `app/`, `desktopApp/`.
- Подключение музыкальной библиотеки одного сервиса и выбор источника аудио:
  особенно Spotify-интеграцию и модули источников.
- Экран плеера: синхронизированные тексты, оформление по обложке,
  анимированные обложки и отображение параметров аудио.
- Поведение воспроизведения: gapless, crossfade и экспериментальный Automix.
- Desktop-дистрибуцию для Windows, Linux и macOS.

Это список направлений для изучения, а не план реализации или подтверждение
пригодности конкретных решений для нашего приложения.
