# Кнопки Media3 в системном плеере Android

- `MediaSessionService` сам публикует медиапанель. На Android 13+ система строит её кнопки из состояния `Player` и настроек `MediaSession`; одновременно помещается до пяти действий, в компактном виде — до трёх.
- Пользовательскую кнопку задают через `CommandButton` и `setMediaButtonPreferences`. Команду нужно добавить в доступные команды контроллера при `MediaSession.Callback.onConnect`, затем обработать в `onCustomCommand`.
- Кнопка сердца по умолчанию попадает в дополнительный слот после основных кнопок воспроизведения. Доступность и порядок отображения на разных версиях Android и оболочках следует проверять на устройстве.
- В Media3 1.8.0 кнопка должна присутствовать в предпочтениях уже при создании сессии: контроллер уведомления переносит начальный список в системный `PlaybackState`. При смене значка обновляем также предпочтения именно контроллера уведомления, чтобы обновился системный список действий.
- В этом проекте реализация находится в `app/src/main/java/com/yellastrodev/dwij/service/PlayerService.kt`. Кнопку показываем для любого трека уже при создании `MediaSession`, а для песни, доступной только в локальной фонотеке (`Song.isLocalOnlyInLibrary`), нажатие игнорируем. Одного Яндекс ID для разрешения лайка недостаточно: ID может относиться к найденному зеркалу локального файла.

Источник: [Android Developers — Media controls](https://developer.android.com/media/implement/surfaces/mobile).
