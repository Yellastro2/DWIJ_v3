# Контекст очереди и смешанные треклисты

`dTracklist.yandexWaveSeed()` явно разрешает ЯМ rotor. По умолчанию null:
внутренние, локальные и VK-списки не отправляются в музыкальное API ЯМ.
Серверные ЯМ-плейлисты используют `playlist:uid_kind`, станции — station ID,
seed-объекты трека/артиста — `track:id` и `artist:id`. В `PlayerRepository`
больше нет перечня исключаемых классов при завершении очереди. `WaveRepository`
тоже отклоняет контекст без seed; null-контекст по-прежнему запускает личную волну.

`MixedTracklistEntry` содержит Song и MusicSource происхождения рекомендации.
`MixedTracklist` хранит снимок этих элементов и выдаёт песни для playQueue;
принимает только уникальные Song.id, чтобы происхождение оставалось однозначным
при shuffle и фильтрации недоступных элементов. Дубли нужно разрешить до создания.
Внутренняя смешанная подборка конечная и не является серверным ЯМ-плейлистом.

`originOf(songId)` возвращает источник сущности в текущем треклисте.
Он независим от PlaybackTrack.source: рекомендация VK может играть из локального
файла либо ЯМ-экземпляра. FullPlayerUiState.queueOrigin берётся из этого контекста,
большой плеер показывает Я / VK / Л рядом с мультисурсом; неизвестное происхождение
не заменяется догадкой по аудиоисточнику.

## «Всё сразу» и «Подборка» (2026-10-07)

HomeMusicSource.All доступен на главной; третья карточка «Подборка» запускает
MixedRecommendationPlayback. Остальные карточки выключены, общий поиск/каталог
показывают статус без обращения к отдельному сервису под видом общего режима.

По нажатию параллельно загружаются playlistOfTheDay ЯМ и audio.getRecommendations
VK. Метаданные обоих списков регистрируются в общем индексе Song. Недоступные
ЯМ-треки без кеша исключаются. alternateRecommendationSongs собирает уникальные
пары ЯМ → VK до конца короткого списка, одноисточниковый хвост не добавляется.
Нераспознанные совпадения между сервисами автоматически не удаляются.
Для каждой песни предпочитается экземпляр исходного сервиса в снимке очереди;
постоянное предпочтение пользователя в БД не меняется.

При ошибке любого запроса новая очередь не запускается. Повторное нажатие
заблокировано до завершения, смена VK-сессии отменяет принятие результата.
Перед запуском останавливается наблюдение ЯМ-волны. preserveQueueOrder запрещает
shuffle/repeat этой очереди, не меняя сохранённых настроек обычного воспроизведения.
После запуска открывается большой плеер с индикаторами происхождения Я/VK.

Тесты MixedTracklistTest и MixedRecommendationOrderTest добавлены;
Gradle и runtime-проверка агентом не запускались.
