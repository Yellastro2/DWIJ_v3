# Назначения радиального меню

Модель и хранилище подключены через `DwijComponent.radialMenuSettingsStore`.
Пять секторов и центральная кнопка запускают коллекции, плейлисты или новую ЯМ-волну.
Пункт «Настроить» открывает редактирование назначений через обычные экраны приложения.

- `RadialMenuTarget.Collection(kind)` — встроенная коллекция текущего аккаунта
  или устройства: локальные треки, любимые, все треки и подборка дня ЯМ, личные/все треки
  и рекомендации VK, смешанная подборка.
- `Playlist(source, key)` — существующий плейлист: локальный `playlistId`,
  ЯМ `playlistUuid` из Room, VK `fullId` (`ownerId_playlistId`).
  VK-репозиторий получает access key из библиотеки при загрузке;
  произвольные внешние плейлисты вне библиотеки этим контрактом пока не обещаются.
  Необязательный title хранится для подписи, состав по нему не восстанавливается.
- `YandexWave(seed)` — исходная станция или seed `track:id`, `artist:id`,
  `playlist:uid_kind`; личная волна — `user:onyourwave`.

Сохраняется способ запуска актуального содержимого. Песни, URL воспроизведения,
batchId и временные UUID очередей сюда не входят. Списки альбома/артиста и снимки
поиска/очереди не поддерживаются.

`RadialMenuSettingsStore` хранит список ровно из пяти назначений; индекс — позиция
сектора. Центральное действие хранится отдельно в поле primary того же JSON.
При отсутствии поля в старых записях используется личная ЯМ-волна, пять секторов
сохраняют свои назначения. Фиксированный пункт «Настроить» не сохраняется. Начальный порядок:
локальные треки → подборка дня ЯМ → любимые ЯМ → рекомендации VK → все треки VK.
Подборка дня не обозначает «Новинки ЯМ»: для последних ещё нужно выбрать
конкретный сценарий приложения.

`HomeRoute` проверяет локальное разрешение, блокирует повторное нажатие на время
подготовки и вызывает `playRadialMenuTarget` из `playback/RadialMenuPlayback.kt`.
Выбранная вкладка музыкального источника не меняет назначение сектора.
Загрузка/ошибки отображаются в snackbar, после принятого запуска открывается плеер.
Локальные треки синхронизируются перед чтением Room; любимые ЯМ обновляются через
PlaylistRepository; плейлист дня запрашивается заново; VK использует getPlaylist
с preferLocal=false и существующей политикой кеша репозитория. Перед конечным
списком прекращается наблюдение ЯМ-волны. Плейлист дня запускается существующим
DailyPlaylistPlayback в application scope.

Главная и экран настройки используют одни назначения и подписи; «Настроить»
с шестерёнкой остаётся шестым сектором только на главной. На экране настройки
рисуются пять назначаемых секторов и кликабельный круг с Play в центре.
Подпись над меню показывает текущее назначение центрального действия.

Короткое нажатие по главной кнопке при отсутствии трека вызывает тот же
startRadialTarget с primaryTarget. При существующем треке остаётся play/pause,
включая возобновление паузы. Выбранная вкладка источника не меняет назначение.
Дефолт центрального действия — user:onyourwave независимо от вкладки.

## Выбор назначения

Нажатие сектора на экране настройки сохраняет его индекс в rememberSaveable в
`DwijApp` и открывает новую главную поверх настройки. Общая панель с «Отмена»
остаётся над NavHost на всех экранах. `LocalRadialMenuSelection` передаёт маршрутам
callback выбора; временный режим не хранится в JSON и не попадает в репозитории.
Для центральной кнопки применяется тот же путь с временным индексом -1;
результат записывается через setPrimaryTarget, а не в список секторов.

- Сетка плейлистов остаётся навигацией. На экране списка общий ObjectScreen
  заменяет запуск кнопкой «Назначить этот список», блокирует нажатия песен и меню.
- Локальные/ЯМ/VK-плейлисты передают ключ объекта; любимые и общие фонотеки — Collection.
- Сетка волн назначает station seed или Collection(YANDEX_DAILY) без запуска.
- Главная назначает личную волну и смешанную подборку вместо воспроизведения.
- Волна по артисту и действие волны по текущему треку в плеере сохраняют seed.
- Списки артиста/альбома, отдельные песни и снимки очередей не назначаются.

После выбора setTarget сохраняет одно назначение; callback очищает режим и делает
popBackStack к настройкам, удаляя временный путь. Отмена делает тот же возврат без
записи. Back внутри пути остаётся обычным; Back с главной выбора возвращает к настройкам.
Возврат к настройкам иным способом также очищает режим. Повторный callback после
завершения игнорируется. «Сбросить меню» восстанавливает пять секторов и личную ЯМ-волну для Play.

В режиме выбора RadialMenu.enabled=false выключает радиальные жесты, поиск не
запускает выбранные песни. Текущее воспроизведение может продолжаться; само назначение
не останавливает волну и не меняет очередь. Компактный плеер корня скрывается, обычный
плеер остаётся доступен с главной для выбора волны по текущему треку.

Одна запись `radial_menu_targets` в существующем `LocalKeyValueStore`:

```json
{
  "version": 1,
  "primary": {"type": "yandex_wave", "seed": "user:onyourwave", "title": "Моя волна"},
  "targets": [
    {"type": "collection", "kind": "LOCAL_TRACKS"},
    {"type": "collection", "kind": "YANDEX_DAILY"},
    {"type": "collection", "kind": "YANDEX_LIKED"},
    {"type": "collection", "kind": "VK_RECOMMENDATIONS"},
    {"type": "collection", "kind": "VK_ALL_TRACKS"}
  ]
}
```

`targets` и `primaryTarget` — StateFlow; `setTarget(index, target)` сохраняет сектор,
`setPrimaryTarget(target)` — центральное действие; `reset()` явно сохраняет оба дефолта. Вызовы изменения последовательные,
на UI-потоке. При отсутствующей или некорректной записи используются дефолты;
чтение само по себе ничего не записывает. Будущая версия также не перезаписывается
до явного изменения. Неизвестный тип или некорректный сектор отклоняет всю запись,
чтобы не сдвигать позиции остальных назначений.

Исходники: `shared/src/jvmCommonMain/kotlin/com/yellastrodev/dwij/RadialMenuTarget.kt`
и `shared/src/jvmCommonMain/kotlin/com/yellastrodev/dwij/data/source/RadialMenuSettingsStore.kt`.
Проверки восстановления: `shared/src/desktopTest/kotlin/com/yellastrodev/dwij/storage/RadialMenuSettingsStoreTest.kt`.

## Проверка в приложении

1. На любой вкладке источника раскрыть меню: пять подписей и «Настроить».
2. Запустить каждый сектор: очередь соответствующего источника и переход к плееру.
3. После ЯМ-волны запустить локальные треки или VK: прежний Rotor больше не пополняет очередь.
4. Проверить отказ локального разрешения, отсутствие авторизации, пустой список и ошибку сети.
5. Во время загрузки повторно выбрать сектор: второй запуск не должен начаться.
6. Открыть «Настроить», выбрать сектор и пройти до плейлиста: кнопка назначения сохраняет
   его и возвращает к настройкам без изменения играющей очереди.
7. Повторить для локального/ЯМ/VK-плейлиста и волны, перезапустить приложение и запустить
   сохранённое назначение с главной.
8. Проверить отмену и Back с главной выбора: прежнее назначение остаётся.
9. В режиме выбора проверить блокировку радиального жеста и нажатий песен; на экране
   альбома нет назначения списка, на экране артиста доступно только назначение волны.
10. В настройках проверить пять секторов без «Настроить» и центральный круг Play.
    Назначить через него плейлист, перезапустить приложение и нажать большую кнопку
    при отсутствии текущего трека: запускается назначенный список. При наличии трека
    короткое нажатие по-прежнему переключает воспроизведение и паузу.
11. Сбросить меню: восстановлены пять дефолтов и центральная «Моя волна» ЯМ.

Gradle и runtime-проверка агентом не запускались.
